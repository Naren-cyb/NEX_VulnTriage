# NEX_VulnTriage
Nexora VulnTriage — a personalised vulnerability triage dashboard that turns free public threat data (NIST NVD, CISA KEV, FIRST EPSS) into a ranked Top-5 action list tailored to each organisation. Dual-persona UI (Owner / IT), explainable scoring, gold-set validated. 24-hour hackathon build (NEX-CODE-SRIKERS).
